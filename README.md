# Nutrisur S.A. - Módulo de Gestión de Inventario y Reposición

Trabajo Práctico Integrador y Progresivo de Organización Empresarial.
Tecnicatura Universitaria en Programación a Distancia - Universidad Tecnológica Nacional.

## Descripción

Nutrisur S.A. es una empresa ficticia dedicada a la distribución mayorista de productos alimenticios envasados. Este repositorio aloja la documentación técnica del Módulo de Gestión de Inventario y Reposición, que registra el stock en tiempo real, emite alertas cuando un producto llega a su punto de pedido y sugiere órdenes de compra a proveedores.
